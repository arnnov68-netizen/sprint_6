# Проект Sprint_6 - Автотесты для «Яндекс.Самокат»

Автотесты для учебного сервиса «Яндекс.Самокат» с использованием Selenium, Page Object Model и Allure-отчётов.

## 📋 Требования

- Python 3.8+
- Mozilla Firefox (последняя версия)
- GeckoDriver (устанавливается автоматически или вручную)

## 🚀 Установка и запуск

### 1. Установка Firefox
Скачайте и установите Mozilla Firefox с официального сайта.

### 2. Установка GeckoDriver
**Вариант 1: Автоматически**
```bash
pip install webdriver-manager
